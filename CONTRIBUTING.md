# Contributing

Thank you for your interest in the Inka Labs tools. Bug reports, ideas and fixes are all welcome.

## Reporting a problem

Open an issue in the tool's repository and choose **Report a problem**. Say what you did, what you expected and
what happened. A screenshot helps. Remove anything private (names, amounts, phone numbers) before you attach it.

## Suggesting an idea

Open an issue and choose **Suggest an idea**. Describe the job you are trying to get done. That matters more
than the feature you have in mind, because there may be a simpler way to get there.

## Sending a change

1. For anything larger than a small fix, open an issue first so the approach can be agreed.
2. Fork the repository and make your change on a branch.
3. Run the tests. Each repository's README says how; most use `pixi run test`.
4. Open a pull request that says what changed and why.

Changes are accepted under the repository's licence.

## Style

- Words on screen are plain and short, written for someone who is not a programmer.
- A tool keeps working without an internet connection wherever it can.
- A user's data stays on their computer unless they choose to send it somewhere.
