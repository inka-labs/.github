# Getting help

- **How a tool works:** each tool has a short tour with screenshots at <https://inka-labs.github.io>.
- **Installing:** the tool's README and the "Read me first" file inside each download explain the steps,
  including the warning your computer may show the first time.
- **Something is not working:** open an issue in the tool's repository and choose **Report a problem**.
- **A security problem:** see the [security policy](SECURITY.md). Please do not report it in a public issue.
