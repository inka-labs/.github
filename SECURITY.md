# Security

If you find a security problem in an Inka Labs tool, please report it privately so it can be fixed before it is
made public.

## How to report

1. Open the repository of the tool on GitHub.
2. Go to the **Security** tab and choose **Report a vulnerability**.
3. Describe what you found, how to reproduce it, and which version you used.

Please do not open a public issue for a security problem.

## What to expect

- A reply within 7 days to confirm the report was received.
- An update when a fix is released, with credit to you if you would like it.

## Scope

Most Inka Labs tools run only on your own computer and keep their data there. Reports that matter most are ones
where another website, another program or another person on the same network could read or change that data.
